# INFERNALIA — Сказания преисподней
Рабочий статический прототип визуальной новеллы (HTML/CSS/JS).

## Публикация на GitHub Pages
1. Создайте публичный репозиторий на GitHub (например, `infernalia`).
2. Распакуйте содержимое ZIP **в корень репозитория**. Файл `index.html` должен лежать в корне, рядом с папками `audio`, `characters`, `lore`, `select`, `story`.
3. В GitHub: Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. Через несколько минут откройте адрес, который покажет GitHub Pages.

## Реализовано
- Главное меню с фоновой композицией и регулировкой громкости.
- Кнопка «Новая игра» → выбор персонажа из полного списка в порядке оглавления лора.
- Просмотр краткого описания и портрета героя.
- Демонстрационная сцена с диалоговым окном и выбором в рамке.
- «Продолжить» возвращает к демонстрации выбранного героя (localStorage в текущем браузере).
- Галерея персонажей с карточками, базовыми сведениями и титулами.
- Листаемый гримуар из исправленного лора.

## Пока не реализовано
- Полноценный сюжет для каждого персонажа; диалоги демо НЕ являются каноном.
- Настоящая система сюжетных сохранений, галерея игрока и достижения.
- Отдельные музыкальные темы персонажей и сюжетные фоны.
- Полная локальная поставка шрифтов: используются Google Fonts при наличии интернета.

## Авторские материалы
Портреты извлечены из переданного документа «ЛОР ПИКЧИ.docx».
Фоновая музыка: SKWLKR — In Your Night (временная, предоставлена пользователем).
Перед публичным размещением репозитория и публикацией GitHub Pages необходимо проверить права на распространение **музыки и изображений**. Для приватного просмотра можно держать репозиторий закрытым и запускать локально.

## Технические замечания
Сайт статический, без сборщика и серверной части. Все пути относительные.
Некоторые браузеры не разрешают автозапуск аудио: нажмите «Включить музыку».
Данные сохранения хранятся только в текущем браузере и могут исчезнуть при очистке его данных.
