# INFERNALIA — Сказания преисподней (v0.6)

Статический прототип для GitHub Pages. Откройте `index.html` или опубликуйте содержимое **этой папки** в корне репозитория.

## Новое
- Создание нескольких собственных персонажей (`creator/`), хранение анкет в браузере.
- Выбор «По лору» (демо) / «Новая судьба», а также «Воля судьбы» / «Перо судьбы» (`mode/`).
- Игровой экран с портретом, автоматическим делением текста на смысловые фрагменты, плавным появлением, отдельной летописью, вводом действий и локальным сохранением (`story/`).
- Уточнён титул Люцифера: Владыка Круга Гордыни. В описаниях Бритни исправлен круг на Гнев.

## Ограничения
**Это прототип без работающей генерации ИИ.** Поля API в настройках остаются демонстрационными. Ключи не вводите до реализации безопасного подключения. «Воля судьбы» пока показывает заглушку вместо генерации. Режим «По лору» пока не воспроизводит полноценный сценарий. Кнопка перегенерации недоступна до API. Галерея игрока ещё в разработке. Анкеты и сохранения хранятся в localStorage конкретного браузера и не синхронизируются.

## Публикация
В GitHub Desktop скопируйте **содержимое** архива в локальный клон репозитория, затем Commit to main → Push origin. Убедитесь, что `index.html`, `creator/`, `mode/`, `story/`, `characters/`, `lore/`, `audio/`, `settings/` находятся в корне репозитория.
