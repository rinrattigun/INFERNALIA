INFERNALIA — прототип главного меню с фоновой музыкой.
Откройте index.html в браузере. Музыка запускается кнопкой «Включить музыку»; браузеры блокируют автоматическое воспроизведение.
Галерея персонажей и гримуар доступны из меню. Новая игра, продолжение и галерея игрока пока не реализованы.
